CI Autopilot analyzes your CI pipeline runs and intelligently optimizes them to reduce build times, lower costs, and improve developer velocity.

## Key Capabilities

- **Intelligent test selection** — Only run tests affected by code changes
- **Pipeline optimization** — Identify and eliminate bottlenecks in your CI workflows
- **Cost reduction** — Reduce CI compute costs by skipping unnecessary work
- **Insights dashboard** — Understand where your CI time and money are going

## Getting Started

CI Autopilot is currently available as a beta to select organizations. [Contact the Trunk team](https://trunk.io/contact) to request access.
