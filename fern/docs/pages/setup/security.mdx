Trunk is committed to keeping your code and data safe. We are SOC 2 Type II certified and follow industry best practices for security.

## Certifications

- **SOC 2 Type II** — Independently audited security controls

## Data Protection

### Encryption

- **In transit** — All data is encrypted using TLS/HSTS
- **At rest** — All data is encrypted using AES-256

### Infrastructure

- Hosted on **AWS** in secure U.S. data centers
- Regular security audits and penetration testing
- Role-based access controls for all internal systems

## Data Retention

- **Test results** are retained for 45 days
- **Merge queue data** is retained for the duration of your subscription
- You can request data deletion at any time

## Responsible Disclosure

If you discover a security vulnerability, please report it to [security@trunk.io](mailto:security@trunk.io).
