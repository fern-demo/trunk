Trunk is a CI reliability platform that helps engineering teams ship code faster and with greater confidence. The platform provides tools to manage merge queues, detect and quarantine flaky tests, and optimize CI pipelines.

## Getting Started

1. **Sign up** at [app.trunk.io](https://app.trunk.io) and create an organization
2. **Connect your repositories** via the Trunk GitHub App
3. **Choose a product** to get started — Merge Queue and Flaky Tests are the most popular starting points
4. **Configure your workflows** using the dashboard or API

## Why Trunk?

- **Faster merges** — Parallel merge queues test non-overlapping PRs simultaneously
- **Fewer broken builds** — Flaky test detection prevents unreliable tests from blocking your pipeline
- **Less developer toil** — Automated quarantining and smart retries save hours per week
- **Enterprise ready** — SOC 2 Type II certified with AES-256 encryption at rest and TLS/HSTS in transit
